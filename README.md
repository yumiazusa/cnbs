# cnbs · 国家统计局数据 MCP

给 AI 接上「官方数据源」：让 WorkBuddy / Claude / Cursor 这类支持 MCP 的客户端，能够**实时取用国家统计局及多家国际组织的统计数据**，而不是凭记忆编数字。

本仓库是**部署与使用资料**（不是服务源码）。服务端基于开源项目 [`mcp-cnbs`](https://www.npmjs.com/package/mcp-cnbs)，以 Node.js + systemd + 宝塔（Apache 反向代理）自建托管。

---

## 数据源

| 数据源 | 工具前缀 | 认证 | 覆盖 |
|---|---|---|---|
| 国家统计局（NBS） | `cnbs_*` | 无 | 国内月度 / 季度 / 年度 / 分省 |
| 世界银行 | `ext_world_bank*` | 无 | 200+ 国家：GDP、贸易、人口、FDI |
| IMF | `ext_imf*` | 无 | WEO 预测、经常账户、政府债务 |
| OECD | `ext_oecd*` | 无 | 成员国季度 GDP、就业、先行指标 |
| BIS | `ext_bis*` | 无 | 有效汇率、信贷缺口、房价 |
| 美联储 FRED | `ext_fred*` | 自备 Key（可选） | 美国利率、汇率、大宗商品 |
| 普查 | `ext_cn_census` | 无 | 人口、经济、农业普查 |
| 部门统计 | `ext_cn_department*` | 无 | 财政、工业、商务、货币、能源 |

共 31 个工具。

## 快速开始（使用者）

在你的 MCP 客户端里添加自定义连接器，粘贴：

```json
{
  "mcpServers": {
    "cnbs": {
      "type": "http",
      "url": "https://cnbs.lets.zone/mcp",
      "headers": {
        "Authorization": "Bearer <向服务提供者索取>"
      }
    }
  }
}
```

保存后**新建一个对话**（旧对话不会自动获得新能力），然后问一句「**你能做什么**」验证是否连通。

完整使用说明见 **[docs/使用手册-学生版.md](docs/使用手册-学生版.md)**：包含 3 个可直接照抄的提问范例、4 个让结果可信的习惯、5 个必踩的坑，以及如何判断 AI 是否在编数据。

## 已知限制

1. **上游按 IP 限流**。短时间内几十次调用后，所有 `cnbs_*` 会返回 `Maximum number of redirects exceeded`，而 `ext_*` 正常。这不是服务故障。不要反复重试，等待几十分钟到数小时自动解除。逐层遍历分类树是最快触发限流的行为。
2. **分省数据当前取不到**。分省数据集（category 6）能定位到节点，但取数阶段失败。需要省级数据请改用统计年鉴 / 中经数据导出后分析。
3. **`cnbs_economic_snapshot` 不可用**。该工具取值逻辑有误，会返回一整排 `null` 或错值，请改用逐指标查询。
4. **时间序列需注意口径**。例如 2022—2023 年就业人员数存在非单调跳变（普查修订所致），不宜直接计算同比增速；城镇登记失业率 2022 年后已停止更新，现行口径为城镇调查失业率。

## 安全说明

- **本仓库不含任何可用令牌**。令牌由服务提供者单独发放，请勿提交到版本库、不要截图外传。
- 服务端令牌通过 `EnvironmentFile` 注入（权限 `600`），不写在 systemd unit 或代码里。
- 该接口仅暴露公开统计数据，但仍建议对公网入口保留 Bearer 鉴权。

## 数据来源与声明

所有数据均来自各发布机构的公开统计接口，遵循其使用条款。国家统计局数据版权归国家统计局所有；世界银行、IMF、OECD、BIS、FRED 数据请按其各自署名要求引用。

本项目仅提供访问通道，不对数据本身的准确性、时效性作担保。**用于论文与报告时，请注明来源、统计期与口径。**
