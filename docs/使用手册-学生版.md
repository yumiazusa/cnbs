# 国家统计局数据查询工具 · 使用手册（学生版）

> 适用对象：已拿到「国家统计局 MCP」连接器地址与令牌的同学，以及任何在自己 WorkBuddy 里装了这个连接器的人。
> 本稿为手册正文的内容源，定稿后同步回 `.docx` 正式稿。
>
> **一句话理解它是什么**：你电脑上的 AI 本来只能"回忆"数据，接上这个连接器之后，它可以**现在去国家统计局的数据库里现取**。区别就像"凭记忆答题"和"当场查资料"。

---

## 一、它能查什么（30 秒看懂）

一个连接器，背后接的是八个数据源：

| 数据源 | 覆盖范围 | 需要额外授权吗 |
|---|---|---|
| 国家统计局（NBS） | 国内月度 / 季度 / 年度 / 分省数据 | 不需要 |
| 世界银行 | 200+ 国家：GDP、贸易、人口、FDI 等 | 不需要 |
| IMF | WEO 预测：增速、经常账户、政府债务 | 不需要 |
| OECD | 成员国季度 GDP、就业、先行指标 | 不需要 |
| BIS | 有效汇率、信贷缺口、房价、跨境银行 | 不需要 |
| 美联储 FRED | 美国利率、汇率、大宗商品、股指 | 需自备 FRED Key（可选） |
| 普查数据 | 人口、经济、农业普查 | 不需要 |
| 部门统计 | 财政、工业、商务、货币、能源 | 不需要 |

**它擅长**：宏观总量、时间序列、跨年对比、跨国对比、结构占比（三次产业、城乡）。
**它不擅长**：企业微观数据、分省细分（服务器侧受限，见第五节）、实时高频行情（那是 iFinD 的活）。

## 二、把它接到你的 WorkBuddy 上（3 分钟）

### 2.1 复制这段配置

在 WorkBuddy 的 **设置 → 连接器 → 自定义连接器 → 添加（JSON 模式）**，粘贴：

```json
{
  "mcpServers": {
    "cnbs": {
      "type": "http",
      "url": "https://cnbs.lets.zone/mcp",
      "headers": {
        "Authorization": "Bearer <向授课教师索取>"
      }
    }
  }
}
```

> 令牌是课堂统一发放的，学期结束后会更换。**请不要把这个文件截图发到公开群**，也不要写进要上交的作业附件里。

### 2.2 保存，然后新建一个对话

保存后**不需要重启 WorkBuddy**，但必须**新建一个对话**——旧对话不会自动获得新能力。

### 2.3 验证是否真的连上了

在新对话里直接问一句：

> **你能做什么？**

判断标准（三条都对才算成功）：

1. 它能列出**跟统计、数据、指标**相关的工具，而不是泛泛而谈；
2. 它提到自己可以查"国家统计局 / 世界银行 / IMF"这类数据源；
3. 你让它查一个简单的东西（比如"最新一期 CPI 同比"），它能给出**带统计期和单位的具体数字**。

如果它说"我没有访问外部数据的能力"，说明连接器没生效——回到 2.1 检查 URL 和令牌，注意 `Bearer` 后面**有一个空格**。

## 三、第一次取数：照抄这三个问题

### 例 1 · 年度趋势（最常用）

> 用国家统计局数据，列出 2016—2025 年中国 GDP 年度值，做成表格，每行注明统计期和单位。数据来源要写清楚。

**你应该拿到**：10 行数据，单位是"亿元"，统计期是"2016 年"到"2025 年"。
**如果只给了 5 行或 8 行**：直接说"年份不全，请补齐 2016 到 2025 全部年份"。

### 例 2 · 最新单指标值

> 查最新一期的居民消费价格指数（CPI）同比涨幅，告诉我统计期、数值、单位。

**你应该拿到**：类似"2026 年 9 月，同比 +0.9%"。
**注意**：它可能给"月度"也可能给"年度"，一定要看它说的统计期对不对。

### 例 3 · 国际对比

> 用世界银行数据对比中国和美国 2020—2024 年的 GDP 增速，做成表格，并说明两国 2020 年差异的原因。

**你应该拿到**：中美各 5 年的增速（%），2020 年中国为正、美国为负。
**这道题的意义**：它走的是世界银行接口，**不受统计局限流影响**，是课堂上的"备用方案"。

## 四、让结果可信的四个习惯

这四个习惯，比会不会用工具重要得多。

**① 把指标名字说死。**
❌ "帮我查点经济数据" → AI 只能瞎猜，还可能去翻分类树，翻着翻着就把服务搞限流了。
✅ "查全国就业人员总数、三次产业就业人员数，2016—2025 年度"。

**② 把年份区间说死。**
❌ "查一下近几年" → 它给你的可能是 5 年，也可能是 3 年，还可能是季度。
✅ "2016—2025，共 10 个年度点"。

**③ 要求标注单位、统计期、来源。**
这是作业的硬要求，也是你判断真假的第一道筛子。一个没有单位的数字，等于没有数字。

**④ 明说"取不到就说取不到"。**
每次提问后面加一句：

> 如果取不到数据，请直接告诉我取不到，不要估算或编造数值。

不加这句，模型在上游失败时很容易"给一个看起来很像的数"。这是所有 AI 取数场景的通用纪律。

## 五、必须知道的五个"坑"

### 坑 1 · 用着用着，突然全部查不到了

**现象**：前面还好好的，忽然所有统计局查询都报错，说"重定向次数过多"或"取数失败"，但世界银行的数据照样能查。
**原因**：国家统计局对**同一个服务器 IP** 做了频率限制。全班几十个人同时查不同的题，几分钟就能把服务器打进限流状态。
**你该做的**：
- **等**。通常几十分钟到几小时自动恢复。
- **不要反复重试**——每一次重试都在延长封禁时间。
- 换**世界银行 / IMF / OECD** 的数据继续做（这三条不受影响）。
- 把这件事写进你的实训记录：这是"公共数据接口的限流机制"，是真实世界的常态，不是故障。

### 坑 2 · 省级数据查不到

**现象**：查"广东 GDP"、"江苏和浙江对比"，它折腾半天然后说取不到。
**原因**：服务器侧的分省数据接口目前不通（已实测确认），不是你的操作问题。
**替代方案**：查**全国**数据；或用世界银行做**跨国**对比；或从中经数据/统计年鉴导出 Excel 后交给 AI 分析（见第七节）。

### 坑 3 · 2022 年和 2023 年的数据"跳"了一下

**现象**：就业人员数 2021 年 74652 万、2022 年 73351 万、2023 年 **74041 万**——降了又升，看起来矛盾。
**原因**：不是错，是**统计口径修订**。国家统计局对 2011—2019 年的数据按第七次全国人口普查结果做过修订，抽样调查也存在样本轮换。
**你该做的**：遇到这种跳变，**不要直接算同比增长率**，在报告里注明"该序列存在口径修订，增速仅供参考"。

### 坑 4 · 同一个指标，两个不同的数字

**现象**：你查 2023 年 GDP，AI 说是 1,294,271.7 亿元，教材上写 1,260,582 亿元。
**原因**：一个是**第五次全国经济普查后的修订数**，一个是**初步核算数**。两个都对，差在修订。
**你该做的**：报告里写清用的是哪一个，别拿两个数混着算增速。

### 坑 5 · 城镇登记失业率 2022 年之后是空的

**原因**：这个指标已经停止更新，现行口径是**城镇调查失业率**（月度发布）。
**你该做的**：如果题目要"失业率"，用**城镇调查失业率**；报告里注明口径。

## 六、怎么判断 AI 在编数据

三个信号，只要中一个就要警惕：

| 信号 | 长什么样 |
|---|---|
| **没有统计期** | "中国 GDP 约为 130 万亿元"——哪一年？不说的基本是猜的 |
| **数字过于整齐** | 一堆 `100`、`500`、`5.0%`，真实统计数据通常有位小数 |
| **拒绝给过程** | 你问"你是怎么取到的"，它绕开不答 |

**最可靠的验证法：换一个数据源再问一次。**
比如问"中国 2024 年 GDP 增速"，先用国家统计局的口径问一遍，再用世界银行的口径问一遍。两个数接近（差 0.1–0.3 个百分点属正常）就基本可信；差得离谱，说明至少有一次是编的。

**要求它交代过程**，可以直接这样问：

> 请说明你刚才用了哪个工具、什么参数取到的这个数。

能说清楚的，通常是真取的。

## 七、数据不够用时怎么办（配合中经数据）

连接器只负责"取数"，不负责"取不到的一切"。遇到取不到的情况（分省、细分行业、年鉴口径），走这条路：

1. 到**中经数据**（`ceidata.cei.cn`）用学校账号登录，按指标名检索；
2. **导出 Excel**；
3. 把 Excel 直接拖进 WorkBuddy，让它做趋势、对比、画图、写结论。

这样"取数"和"分析"分工，各自用最合适的工具，也不用把账号密码交给 AI。

## 八、速查表

### 8.1 常用指标怎么问

| 想查什么 | 就这样说 |
|---|---|
| 经济总量 | 国内生产总值（GDP）年度值 |
| 物价 | 居民消费价格指数（CPI）同比 |
| 工业品价格 | 工业生产者出厂价格指数（PPI） |
| 制造业景气 | 制造业采购经理指数（PMI） |
| 消费 | 社会消费品零售总额 |
| 投资 | 固定资产投资完成额 |
| 货币 | M2 货币供应量 |
| 就业 | 就业人员数 / 城镇调查失业率 |
| 人口 | 年末总人口 / 城镇化率 |
| 收入 | 居民人均可支配收入 |

### 8.2 时间怎么写

| 频率 | 写法 | 例子 |
|---|---|---|
| 年度 | `YYYYYY`（四位年 + YY） | `2016YY-2025YY` |
| 月度 | `YYYYMM` | `201601MM-202512MM` |
| 季度 | 年在后加 A/B/C/D | `2024A`=一季度，`2024D`=四季度 |
| 快捷 | `LAST6` / `LAST12` | 最近 6 期 / 12 期 |

### 8.3 常用地区代码

| 地区 | 代码 |
|---|---|
| 全国 | `000000000000` |
| 北京 | `110000000000` |
| 上海 | `310000000000` |
| 江苏 | `320000000000` |
| 浙江 | `330000000000` |
| 广东 | `440000000000` |

（其余省份可以让它自己查，但注意：查地区容易触发限流，见坑 1。）

### 8.4 下面这个工具不要用

如果 AI 调用了"经济快照"这类"一次返回十个核心指标"的工具，结果可能出现**一整排 null**，或者给出明显错误的指标（比如把"贡献率"当成增速）。这是已知问题，**改用逐个指标查询**即可。看到一排 null，不要以为是没数据，换一种问法就行。

## 九、交作业时的引用规范

数据可以来自 AI，但**责任在你**。三件事必须做：

1. **标来源**：`数据来源：国家统计局，经 WorkBuddy 数据连接器于 2026-11-01 取得`；
2. **标单位与统计期**：每个表格都要有，缺了就是不合格；
3. **口径有差异就说明**：比如"本文采用初步核算数"、"该序列按七普修订，增速仅供参考"。

加分项：同一个指标用两个来源交叉验证，并在报告里写一句"两源差异 X 个百分点，原因可能是……"。

## 附：给教师 / 管理员的四条出题纪律

这一节学生可以跳过。

1. **全班用同一套题（3–5 道）**，不要一人一题。相同问题第二次提问会命中服务器缓存，不打上游。
2. **课前先跑一遍预热**，用与学生完全相同的问法（参数差一个就命中不了缓存）。
3. **题目里写明指标名和年份区间**。开放式提问（"帮我找找失业率在哪"）会让 AI 逐层翻分类树，二十几次调用就能触发限流。
4. **每题准备一条国际源备选**（世界银行 / IMF），限流时立刻切换，课不中断。
